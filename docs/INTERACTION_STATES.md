# EthanFitnessRecord：页面状态与危险操作清单

> 阶段 3 工作文档。用于保证正常、首次使用、空数据、加载、错误和边界状态均有明确交互。

## 1. 全局状态原则

- 首次使用时只要求完成当前任务需要的最少设置，不一次索取全部信息；
- 空数据页面说明“为什么为空”和“下一步可以做什么”；
- 加载状态保留页面结构，避免重复提交；
- 校验错误就近显示在对应字段下方，保留用户已经输入的内容；
- 本地存储失败时不显示虚假的成功状态，并允许重试；
- 删除、覆盖、导入替换和清空必须明确说明影响范围；
- 用户取消危险操作时，数据和页面状态完全不变；
- 所有关键操作都可用文字理解，不只依赖颜色和图标。

## 2. 首页状态

| 状态 | 显示内容 | 主要操作 |
| --- | --- | --- |
| 首次使用 | 无当前体重、无目标体重、用途说明 | 设置目标、记录第一条体重 |
| 今日未记录 | 最近体重、目标体重、今日 0/3 | 记录体重 |
| 今日已记录 | 当前体重、今日次数、最近趋势 | 再次记录、查看趋势 |
| 今日已达上限 | 今日 3/3，说明需编辑或删除 | 查看今日记录 |
| 今日休息 | 明确显示休息日 | 查看本周计划 |
| 今日训练 | 最多 2 个训练组合 | 查看组合、开始训练 |
| 读取失败 | 不展示可能过期的汇总 | 重试、进入设置查看数据说明 |

## 3. 体重记录状态

| 状态 | 反馈与处理 |
| --- | --- |
| 默认 | 预填当前日期和时间，不预填未经确认的体重 |
| 非数字或为空 | 字段下显示“请输入有效体重” |
| 小于 20.0 或大于 300.0 kg | 显示允许范围，不保存 |
| 未来时间 | 显示“不能记录未来时间”，保留其他输入 |
| 当天已达 3 条 | 禁止新增，列出当天记录供编辑或删除 |
| 保存中 | 禁用重复保存，显示进行中反馈 |
| 保存成功 | 返回来源页面并刷新首页和趋势 |
| 保存失败 | 保留输入，说明数据未保存，提供重试 |
| 删除 | 确认框显示具体体重和时间；取消不变，确认只删除目标记录 |

## 4. 趋势状态

| 状态 | 反馈与处理 |
| --- | --- |
| 无数据 | 不画虚假折线，显示记录第一条体重入口 |
| 单点 | 显示独立数据点，说明数据不足以形成趋势 |
| 多点 | 每条记录一个点，严格按时间连接 |
| 同日 3 点 | 同一天显示 3 个点，并可查看各自时间 |
| 长周期 | 减少横轴标签密度，但保留全部数据点和准确值 |
| 目标未设置 | 不显示目标线，提供设置目标入口 |
| 数据异常 | 跳过无法解析的单条数据并提示检查，不修改原始数据 |

## 5. 周计划和训练状态

| 状态 | 反馈与处理 |
| --- | --- |
| 空计划 | 显示新建、复制上周和获取建议三个入口 |
| 休息日 | 明确标记休息，可改为训练 |
| 1 个组合 | 允许添加第 2 个组合 |
| 2 个组合 | 显示 2/2，禁止添加第 3 个组合 |
| 复制上周 | 先展示将复制的日期范围和冲突说明，确认后复制 |
| 推荐条件不完整 | 指出缺失项，不生成不可靠建议 |
| 推荐无匹配动作 | 说明哪些器械或排除条件导致无结果，允许返回修改 |
| 与已有计划冲突 | 保存前列出受影响日期，未经确认不覆盖 |
| 训练进行中 | 可逐项勾选，离开后保留实际完成数据 |
| 保存失败 | 保留编辑内容，原计划不变，允许重试 |

## 6. 动作库状态

| 状态 | 反馈与处理 |
| --- | --- |
| 正常列表 | 中文名称、缩略图、肌群、器械和难度 |
| 搜索无结果 | 显示当前关键词并提供清除搜索 |
| 筛选无结果 | 说明当前筛选条件并提供重置 |
| 无收藏 | 说明收藏用途并返回全部动作 |
| 图片或动画缺失 | 显示占位图，动作文字和安全信息保持完整 |
| 收藏保存失败 | 恢复原状态并提示重试，不显示虚假成功 |

## 7. 设置与数据管理状态

| 状态 | 反馈与处理 |
| --- | --- |
| 目标体重非法 | 显示 20.0–300.0 kg 范围，不保存 |
| 导出成功 | 显示文件名称、时间和后续保存方式 |
| 导出失败 | 说明未生成备份，提供重试 |
| 导入校验中 | 禁止重复选择，当前数据不变 |
| 文件损坏 | 明确说明无法读取，当前数据不变 |
| 版本不兼容 | 显示文件版本和支持版本，当前数据不变 |
| 导入摘要 | 显示体重、计划、完成记录、收藏和设置数量 |
| 完整替换确认 | 明确说明先自动备份，再替换全部个人数据 |
| 导入失败 | 自动回滚，说明原数据仍保留 |
| 分类清空确认 | 显示将删除的数据类别和数量 |
| 清空全部确认 | 第一次说明范围，第二次要求再次确认；内置动作库保留 |
| 清空失败 | 显示未完全执行并从事务前备份恢复 |

## 8. 危险操作确认文案原则

- 标题直接描述操作，例如“删除这条体重记录？”；
- 正文展示具体对象、数量和不可逆影响；
- 取消按钮使用中性文案“取消”；
- 确认按钮使用具体动词“删除记录”“替换数据”“清空全部”；
- 默认焦点和视觉强调不放在危险操作上；
- 导入替换和清空全部必须说明自动备份或恢复方式。
