### 微信开发者工具

系统当前只检测到普通微信客户端 `/Applications/WeChat.app`，未检测到微信开发者工具。

完成方式：

1. 从微信官方开发者工具下载页安装 macOS 稳定版。
2. 登录微信开发者工具。
3. 导入本项目根目录。
4. 第一轮使用测试号运行；准备真机调试时再填写个人小程序 AppID。
5. 成功编译后，将实际使用的基础库版本固定在 `project.config.json`，不再使用 `trial`。

### 发布相关配置

以下内容在 MVP 开发完成前不需要准备：

- 正式小程序 AppID
- 微信云开发环境
- `miniprogram-ci` 上传密钥
- 隐私保护指引与正式发布资料

## 环境原则

- 初期不安装 UI 框架、图表库或状态管理库。
- 确认原生能力不足后再引入依赖，并记录引入理由、版本和许可证。
- `project.private.config.json` 属于本机配置，不提交版本库。
- AppID、上传私钥和服务端密钥不得写入仓库。
