# EthanFitnessRecord：素材来源与许可证登记表

> 所有进入正式小程序的图标、图片、动画、字体和第三方视觉资源，都必须先登记并完成许可证核验。

## 使用规则

1. 未登记或许可证不明确的素材不得进入正式版本；
2. 优先使用项目原创素材、系统字体和自行绘制的界面图形；
3. 允许商用不代表可以不署名，须按许可证要求处理；
4. 外部素材必须保留来源链接、作者、许可证名称、下载日期和本地文件位置；
5. 替换素材时不得删除原登记历史，应新增状态说明；
6. openGym 只作为产品体验参考，不复制其代码、图标、截图或动作媒体。
