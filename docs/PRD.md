# MVP 产品需求

## 1. 产品目标

为单个用户提供一个轻量、私密、每天愿意打开的减脂与增肌记录工具。核心价值不是社交或排行榜，而是持续记录、看懂趋势、按计划训练。

## 2. 目标用户

- 主要用户：项目所有者本人
- 使用设备：微信可运行的小屏手机
- 使用频率：每天记录体重，每周查看或调整训练计划，训练时查看动作指导

## 3. 核心场景

### 3.1 记录体重

用户可记录当天体重，可补录历史记录，也可修改或删除错误数据。同一天默认只保留一条记录，重新保存时明确提示覆盖。

### 3.2 查看趋势

用户可切换 7 天、30 天、3 个月和全部时间范围。折线图同时显示实际体重与目标体重，并展示起始值、当前值和阶段变化。

### 3.3 获得训练建议

用户填写训练目标、经验、每周可训练天数、每次时长、可用器械和身体限制。程序基于规则推荐一份可解释的周计划，用户确认后才保存。

### 3.4 自定义周计划

用户可以为周一至周日设置训练或休息，创建训练组合，添加动作并配置组数、次数、负重、时长和休息时间。

### 3.5 查看动作指导

动作详情至少包含名称、目标肌群、所需器械、动作步骤、常见错误和安全提示。动图素材必须具有明确可用的授权。

## 4. 第一版页面

1. 首页：今日摘要、快速记录体重、今日训练、最近趋势。
2. 趋势：体重折线图、范围切换、历史列表。
3. 计划：周日历、推荐计划、自定义训练。
4. 动作库：筛选、搜索、收藏、动作详情。
5. 设置：目标体重、单位、导入导出、数据说明。

## 5. 暂不进入 MVP

- 摄像头姿态识别与自动计数
- 社区、排行榜、好友关系
- 饮食热量识别
- 付费、广告和会员
- 医疗诊断或伤病治疗建议
- 未经用户确认自动修改训练计划

## 6. MVP 完成标准

- 离线状态下可完成记录、查看、计划和动作浏览
- 关闭并重新打开小程序后数据仍存在
- 连续 90 天体重数据绘图流畅且数值正确
- 所有删除、覆盖和清空操作均有明确确认
- 空数据、异常数据和首次使用状态都有可理解的界面
- 关键流程在微信开发者工具和至少一台真机通过验收
