# MVP 产品需求

## 0. 产品信息

- 正式名称：`EthanFitnessRecord`
- 名称状态：已由用户于 2026-09-02 确认
- 一句话定位：记录体重变化，规划每周减脂增肌训练。
- 定位状态：已由用户于 2026-09-02 确认

## 1. 产品目标

为单个用户提供一个轻量、私密、每天愿意打开的减脂与增肌记录工具。核心价值不是社交或排行榜，而是持续记录、看懂趋势、按计划训练。

## 2. 目标用户

- 主要用户：项目所有者本人
- 使用设备：微信可运行的小屏手机
- 使用频率：每天记录体重，每周查看或调整训练计划，训练时查看动作指导

## 3. 核心场景

### 3.1 记录体重

用户可记录当天体重，也可补录、修改或删除历史记录，具体规则如下：

- 体重单位固定为公斤（kg），保存和显示时保留 1 位小数；
- 体重与目标体重的有效范围均为 20.0–300.0 kg；
- 每天最多保留 3 条体重记录，每条记录包含具体日期和时间；
- 达到上限后必须先修改或删除当天已有记录，不能直接新增第 4 条；
- 可以补录历史记录，但不能选择未来的日期或时间；
- 可以修改已有记录；删除前必须二次确认；
- 目标体重可以随时调整，调整后不修改任何历史记录；
- 每日记录属于自愿行为，不要求连续打卡，也不因漏记产生惩罚性提示。

### 3.2 查看趋势

用户可切换 7 天、30 天、3 个月和全部时间范围。每一次体重记录都在折线图中显示为独立数据点，同一天最多显示 3 个点，并严格按记录时间先后连接，不计算或替换成每日平均值。折线图同时显示目标体重，并展示起始值、当前值和阶段变化。

### 3.3 获得训练建议

第一版使用完全本地运行的规则引擎生成训练建议，不调用联网 AI 服务。用户提供以下输入：

- 训练目标：减脂、增肌或两者兼顾；
- 训练经验：新手、进阶或熟练；
- 每周可训练天数；
- 每次可训练时长；
- 可用器械；
- 重点训练部位；
- 不适合或不想做的动作；
- 期望强度：低、中或高。

程序输出一份包含每周训练日、训练组合、动作、组数、次数和休息时间的建议计划，并展示推荐依据。用户可以修改或拒绝建议；只有明确确认后才能保存，且不得自动覆盖已有计划。身体限制只用于排除动作和显示安全提醒，不用于疾病诊断或康复处方。

### 3.4 自定义周计划

用户可以创建和维护周一至周日的训练计划，具体规则如下：

- 每天可以设为“训练”或“休息”；
- 每天最多安排 2 个训练组合；
- 训练类型包括力量、有氧、拉伸恢复和自定义；
- 每个动作包含动作名称、执行顺序、组数、次数、负重、单组时长、组间休息和备注；
- 次数、负重和单组时长根据动作类型选填，不要求所有动作同时填写；
- 徒手动作不要求填写负重；
- 计划中的动作支持添加、删除、排序和替换；
- 支持复制上一周计划，复制后可以独立修改，不影响原计划；
- 训练完成后可以勾选，并记录实际完成情况；
- 超过每天 2 个训练组合时阻止保存，并给出明确提示。

### 3.5 查看动作指导

MVP 首批收录约 30 个常用动作，覆盖胸、背、腿、肩、手臂、核心、有氧和拉伸，具体规则如下：

- 动作只显示中文名称，不显示英文名称；
- 每个动作包含主要肌群、辅助肌群、所需器械、难度、分步骤说明、呼吸节奏、常见错误、安全注意事项和可替换动作；
- 动作库支持收藏、中文搜索和按身体部位筛选；
- 列表使用静态缩略图，详情页使用循环动画；
- 图片和动画只能使用原创素材或许可证明确允许使用的素材；
- 素材授权未确认时只显示文字和占位图，不得直接复制 openGym 或其他产品的素材。

### 3.6 数据管理

所有个人数据默认只保存在手机本地，不自动上传。用户可以主动导出、导入或清空数据，具体规则如下：

- 导出格式为带数据结构版本号的 JSON 备份文件；
- 备份包含体重记录、目标体重、训练计划、训练完成记录、动作收藏和个人设置；
- 内置动作库、缩略图和动画不重复导出；
- 导入前必须完整校验文件格式、版本和字段，并向用户展示数据摘要；
- MVP 只支持“完整恢复并替换”，暂不支持合并两份数据；
- 用户确认导入后，程序先自动备份当前数据，再执行替换；
- 文件错误、版本不兼容或导入失败时，原数据保持不变；
- 支持分别清空体重数据、训练数据和收藏；
- 清空全部个人数据需要二次确认，且不会删除内置动作库；
- 导出、导入与清空只能由用户主动触发。

## 4. 第一版页面

1. 首页：今日摘要、快速记录体重、今日训练、最近趋势。
2. 趋势：体重折线图、范围切换、历史列表。
3. 计划：周日历、推荐计划、自定义训练。
4. 动作库：筛选、搜索、收藏、动作详情。
5. 设置：目标体重、单位、导入导出、数据说明。

## 5. 暂不进入 MVP

- 摄像头姿态识别与自动计数
- 社区、排行榜、好友关系
- 饮食热量识别
- 付费、广告和会员
- 医疗诊断或伤病治疗建议
- 未经用户确认自动修改训练计划

## 6. MVP 完成标准

- 离线状态下可完成记录、查看、计划和动作浏览
- 关闭并重新打开小程序后数据仍存在
- 连续 90 天体重数据绘图流畅且数值正确
- 所有删除、覆盖和清空操作均有明确确认
- 空数据、异常数据和首次使用状态都有可理解的界面
- 关键流程在微信开发者工具和至少一台真机通过验收
