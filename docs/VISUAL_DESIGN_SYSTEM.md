# EthanFitnessRecord：视觉规范与组件设计

> 阶段 4 冻结文档。当前状态：视觉方向、设计变量、组件规格和核心页面高保真审阅稿已确认并冻结。

## 1. 视觉方向

- 关键词：克制、专注、可靠、运动感；
- 主题：固定深色主题，降低夜间记录体重和训练时的视觉刺激；
- 强调色：高辨识度活力绿色，用于主操作、选中状态和体重趋势主线；
- 信息表达：中文优先，数字清晰，避免大面积装饰和无意义渐变；
- 参考边界：借鉴 openGym 的深色运动气质和清晰层级，不复制其代码、图标、布局细节或媒体素材；
- 品牌显示：页面标题使用 `EthanFitnessRecord`，功能名称与操作说明使用中文。

## 2. 颜色变量

| 变量 | 建议值 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#0A0F0D` | 页面底色 |
| `--color-surface` | `#121A16` | 卡片与底部导航 |
| `--color-surface-raised` | `#18231D` | 弹窗、选中卡片与浮层 |
| `--color-primary` | `#61E786` | 主按钮、趋势线、完成状态 |
| `--color-primary-pressed` | `#49C96E` | 主按钮按下状态 |
| `--color-primary-soft` | `rgba(97, 231, 134, 0.14)` | 标签、选中背景 |
| `--color-text` | `#F4F8F5` | 主要文字 |
| `--color-text-secondary` | `#9AAC9F` | 次要说明与时间 |
| `--color-border` | `rgba(244, 248, 245, 0.10)` | 分隔线和输入框边界 |
| `--color-overlay` | `rgba(0, 0, 0, 0.62)` | 弹窗遮罩 |
| `--color-disabled` | `rgba(244, 248, 245, 0.32)` | 禁用文字与图标 |
| `--color-warning` | `#F6C85F` | 上限、需注意状态 |
| `--color-danger` | `#FF6B6B` | 删除、清空和错误 |

规则：绿色只强调当前任务和积极状态；危险操作始终使用危险色与文字共同表达；正文不使用低对比度绿色。

## 3. 字体与数字

- 字体族：系统字体，优先 `PingFang SC`，不引入外部字体文件；
- 字重：常规 400、强调 500；
- 字号：12、14、16、20、28 px 五级；仅体重主值可使用 36–40 px 的数据展示字号；
- 行高：正文约为字号的 1.5 倍，标题约为 1.3 倍；
- 体重、次数和日期数字使用等宽数字特性；
- 体重主值显示到 1 位小数，单位 `kg` 使用次一级字号；
- 不用全大写英文，不用长英文充当中文功能名称。

| 项目 | 规格 |
| --- | --- |
| 基础间距 | 4 px 网格 |
| 页面左右边距 | 16 px |
| 内容区块间距 | 20–24 px |
| 卡片内边距 | 16 px |
| 小/中/大圆角 | 8 / 12 / 20 px |
| 弹层上圆角 | 20 px |
| 主按钮高度 | 48 px |
| 普通控件最小高度 | 44 px |
| 图标视觉尺寸 | 20–24 px |
| 最小触控区域 | 44 × 44 px |
| 底部安全区 | 使用 `env(safe-area-inset-bottom)` |

阴影只用于浮层和弹窗；普通卡片主要依赖色阶与间距建立层级。

### 4.1 布局与安全区

- 设计基准宽度为 375 px，同时覆盖 360 px 窄屏和 736 px 宽屏预览；
- 一级页面左右边距保持 16 px，内容不使用固定宽度；
- 顶部内容避开胶囊与系统状态区，底部导航在安全区之上保留 12 px 视觉内边距；
- 页面允许纵向滚动，不允许因中文、数字或标签产生横向滚动；
- 系统字体放大时，标签和按钮允许增高，文字不截断，主操作保持完整可见。

## 5. 通用组件规格

### 5.1 按钮

- 主按钮：绿色实底、深色文字，每个操作区域最多一个；
- 次按钮：深色抬升表面、浅色文字；
- 文字按钮：无背景，用于返回、取消和低优先操作；
- 危险按钮：危险色文字或危险色实底，只在确认流程中出现；
- 加载时保留原宽度并禁止重复点击。

### 5.2 输入框

- 标签位于输入框上方，不以占位文字替代标签；
- 体重输入采用大数字与固定 `kg` 后缀；
- 错误文案紧邻字段并保留原输入；
- 聚焦状态使用绿色边界和轻微外圈，不改变布局尺寸。

### 5.3 卡片

- 标准卡片只承载一个明确主题；
- 卡片标题、主要数值和辅助说明形成三级层次；
- 可点击卡片显示方向提示或明确操作文案；
- 不使用卡片嵌套卡片。

### 5.4 标签与状态

- 标签用于肌群、器械、难度和完成状态；
- 同类标签只使用一种颜色，不做彩虹式编码；
- `休息`、`完成`、`2/2` 等状态必须同时显示文字。

### 5.5 弹窗与提示

- 弹窗标题直接说明操作；
- 危险操作正文包含对象和影响范围；
- 取消操作优先排列，危险确认不作为默认焦点；
- 成功反馈短暂显示，失败反馈保留到用户处理或关闭。

### 5.6 底部导航

- 固定 5 项：`首页 / 趋势 / 计划 / 动作 / 设置`，顺序不得变化；
- 图标使用统一 24 × 24 px 单色线性图形，文字为 12 px；
- 单项触控区不小于 56 px 高，选中项同时改变图标与文字颜色；
- 未选中项使用次级文字色，不通过透明度降低到不可读；
- 图标必须配中文标签，不使用仅图标导航。

### 5.7 状态与可访问性

- 聚焦态使用 2 px 绿色外圈，外圈不占布局尺寸；
- 禁用控件保留文字，降低到禁用色，同时不可响应点击；
- 警告、错误、完成、选中均使用“颜色 + 文字或形状”双重表达；
- 正文、按钮与关键数据需满足清晰可读的对比度，绿色不用于长段正文。

## 6. 专用组件规格

### 6.1 体重折线图

- 绿色实线表示体重记录，圆点表示每一次记录；
- 目标体重使用较弱的水平虚线并直接标注；
- 同一天最多 3 个点，按真实时间顺序连接；
- 横轴为日期/时间，纵轴明确标注 `kg`；
- 点击数据点显示日期、时间和准确体重；
- 无数据和单点状态不绘制虚假趋势。

### 6.2 周计划

- 一周日期使用水平分布的 7 个日期按钮；
- 当前日期、选中日期和有训练日期分别使用位置、填充和圆点表达；
- 每天最多 2 个训练组合，达到上限后显示 `2/2`；
- 休息日作为正常状态呈现，不使用警告色。

### 6.3 动作卡片

- 缩略图比例固定，缺失时使用统一占位；
- 中文动作名为主标题；
- 主要肌群、器械和难度保持一行或自然换行；
- 收藏操作有文字可访问名称；
- 动作详情中的步骤、呼吸、安全提示按阅读顺序排列。

## 7. 一级页面高保真规格

### 7.1 首页

- 首屏顺序：日期问候 → 当前体重卡 → 最近趋势 → 今日训练；
- 当前体重是唯一大号数字，目标体重和记录次数作为辅助信息；
- “记录体重”是首屏唯一绿色实底按钮；
- 趋势摘要只显示必要折线与阶段变化，不替代完整趋势页。

### 7.2 趋势

- 时间范围使用 4 等分分段控件，当前范围以抬升表面显示；
- 图表卡优先保证折线、每次记录点、目标线与单位可读；
- 最高、最低和记录次数为并列摘要，不使用多种强调色；
- 长周期只降低横轴标签密度，不省略实际记录点。

### 7.3 计划

- 一周 7 日同屏显示，当前日、选中日、有计划日分别使用文字、填充与圆点区分；
- 当天组合以左侧绿色标记建立扫描顺序，最多显示两张；
- `2/2` 同时表达已达当天上限，不再显示新增入口；
- 休息日使用中性色，并将“改为训练”作为次操作。

### 7.4 动作

- 搜索框、部位筛选和列表按顺序排列；
- 动作图比例固定为约 5:4，缺失素材时显示统一文字占位；
- 中文名称优先，肌群与器械标签换行时不挤压收藏触控区；
- 收藏状态通过图形填充和可访问名称共同表达。

### 7.5 设置

- 目标与单位、数据管理、说明信息分组，不使用卡片套卡片；
- “仅存本机”作为隐私状态提示，不误导为云同步状态；
- 导出、导入与清空按风险从低到高排列；
- 清空全部使用危险色文字，最终执行仍必须进入二次确认。

该稿包含首页、趋势、计划、动作、设置 5 个一级页面，以及体重记录底部弹层示例。它只用于阶段 4 视觉验收，不接入数据、不保存输入、不实现业务流程。预览中的动作图和导航符号均为占位表达，正式图形须按本文件第 8 节的原创规格绘制。

第一轮重点确认：

1. 深色背景与活力绿色是否符合预期；
2. 当前体重是否形成清楚但不过度夸张的首屏焦点；
3. 趋势、周计划和动作列表的信息密度是否舒适；
4. 中文正文、辅助文字和数字的层级是否清晰；
5. 底部 5 项导航是否容易识别。
